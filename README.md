# Tabelas com CSS Grid

Este projeto é uma atividade prática desenvolvida para exercitar a criação e estilização de estruturas de dados em formato de tabela utilizando **CSS Grid** em vez da tradicional tag HTML `<table>`. 

O objetivo é explorar o controle de layout bidimensional oferecido pelo Grid, garantindo responsividade, flexibilidade e um design moderno.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização e layout bidimensional utilizando `display: grid`.

---

## 🎯 Conceitos Praticados

- **`display: grid`**: Transformação do contêiner em um contexto de grid.
- **`grid-template-columns`**: Definição das colunas da tabela e distribuição de espaço (uso de unidades como `fr`, `px`, `%` ou `repeat()`).
- **`gap` / `grid-gap`**: Espaçamento entre células e linhas da tabela.
- **Alinhamento de Conteúdo**: Uso de `align-items` e `justify-content` para centralizar dados nas células.
- **Responsividade**: Adaptação da estrutura para telas menores utilizando `@media` queries e funções como `minmax()`.
